# Veynrel 2.0.1

A focused reliability and large-vault UX update.

## Knowledge Health

- Deep Knowledge analysis shows real progress during long runs, with actual stages, note/batch counters and elapsed time.
- Running state clears correctly after success, failure and cancellation; restarted runs begin with fresh progress.

## Semantic Map

- Inspect large vaults with an expanded 0.4–24× zoom range, wheel zoom, pan, and visible zoom, reset and fit controls.
- Markers and hit targets remain readable while zooming. Similarity and connectedness scores are unchanged; viewport changes reuse the existing map.

## Vault Audit

- Clearer descriptions distinguish changed-note detailed audits, full detailed audits and overview/report workflows.
- Counts and cache behavior are clearer. Batch + Report explicitly describes its processed new/stale subset; it does not combine all cached notes into a whole-vault synthesis.

## Compatibility / polish

- Clean up the reported Community CSS compatibility patterns while preserving the accessible Health status region, reduced-motion support and theme-native presentation.
- Preserve proposal scrolling and bounds at normal, narrow and short window sizes.
- No persistence migration or semantic index rebuild is required solely by this update. Existing compatible settings and data remain supported.
